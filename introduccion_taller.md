# ¿Cómo y cuándo utilizar las herramientas?

## Google classroom: 

Lo utilizaremos para poder visualizar los materiales de la clase, hacer entregas de ejercicios, recibir feedback, y hacer consultas. Ahí tendrán que subir todos sus trabajos para recibir sus calificaciones.

## Google drive.

Será donde guarden sus archivos como especie de repositorio. Es muy importante que se tomen 5 minutos antes de finalizar la clase para que guarden y suban sus archivos de proyectos y no perder el avance. Recordemos que las cuentas de usuario de la computadora limpian y borran todos lo archivos una vez que se cierra sesión, por lo que tendremos que hacer uso de google drive para poder guardar y volver a acceder a los proyectos.

## VS Code 

Es la herramienta con la que más vamos a trabajar, ya que este es nuestro editor de código, donde escribiremos, probaremos y desarrollaremos los proyectos. Principalmente nos tenemos que asegurar que tenemos seteada la opción de *"Autosave"* para evitar perdidas de información por cerrar el programa equivocadamente o algún fallo de la computadora. Una vez está configurado todo, ya podremos empezar a codear.

## Tumo path 

Si bien es la herramienta que menos usaremos, tendrán que abrir su path para poner el presente cada día. Es importante hacer nuestra check list para asegurarnos que todo está listo para que el desarrollo de la clase sea adecuado para cada uno.

### Los pasos a seguir son:

#### Para El inicio.

1. Iniciar sesión como invitado en la iMac.
2. Iniciar sesión en la cuenta de tumo.world y establecer el estado de "Presente" 
3. Iniciar sesión en la cuenta de google y abrir Drive para descargar / subir archivos de nuestros proyectos.
4. Abrir VSCode y desde la ventana "File" establecer el Autoguardado ó "Auto Save".


#### Para el cierre.
1. Guardar nuestro proyecto o asegurarnos que esté guardado correctamente.
2. Subir el proyecto a Drive.
3. En caso de haber terminado alguna de las tareas entregables, subirla al classroom.
4. Cerrar sesión de todas las cuentas, incluida la sesión de la iMac para dejar todo listo para el siguiente grupo.

## Importante

Esta será una experiencia para que todos los que participen puedan disfrutar y aprovechar para aprender, dedíquenle tiempo y esfuerzo, así lograrán tener buenos proyectos.
